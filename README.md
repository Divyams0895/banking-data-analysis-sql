# Banking Data Analysis Using SQL (MySQL)

## Project Overview

This project focuses on analysing banking data using MySQL to extract meaningful insights and answer real-world business questions.

The analysis explores customer demographics, bank accounts, transactions, loan performance, branch performance, and customer support operations.

The main objective is to strengthen SQL skills and demonstrate how relational databases can be used to solve business problems.

## Database Tables

The project works with the following banking entities:

- Customers
- Accounts
- Transactions
- Loans
- Loan Payments
- Branches
- Support Tickets

## Key Analysis Performed

### 1. Customer Analysis
- Identified the oldest customers.
- Analysed male and female customer counts.
- Identified customers with multiple accounts.
- Calculated customer distribution by city.
- Analysed average customer age.

### 2. Account Analysis
- Calculated total account balance.
- Analysed average balance by account type.
- Identified accounts with the highest balances.
- Analysed active, inactive, and dormant accounts.
- Identified customers with both Savings and Current accounts.

### 3. Transaction Analysis
- Calculated successful transactions.
- Analysed deposit and withdrawal amounts.
- Identified top customers by transaction amount.
- Analysed monthly transaction volume.
- Calculated failed transaction percentage.
- Explored running totals and month-over-month growth.

### 4. Loan Analysis
- Calculated total loan amounts.
- Analysed loan counts by type.
- Identified customers with multiple loans.
- Analysed successful loan repayments.
- Identified late and missed payments.

### 5. Branch and Customer Support Analysis
- Identified branches with the highest number of accounts and transactions.
- Calculated branch-wise transaction amounts.
- Identified common customer complaint categories.
- Calculated average ticket resolution time.

### 6. Advanced SQL Analysis
- Ranked top customers by successful transaction amount.
- Calculated month-over-month transaction growth.
- Identified first and latest transaction dates.
- Identified customers inactive in the last 90 days of the dataset.
- Calculated account-wise running totals.
- Segmented customers into High, Medium, and Low-value groups.
- Explored potentially unusual transactions.

## SQL Concepts Used

- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- Aggregate functions: SUM(), COUNT(), AVG(), MIN(), MAX()
- Subqueries and Common Table Expressions (CTEs)
- CASE WHEN
- Window Functions: RANK(), LAG(), NTILE()
- Date Functions: DATEDIFF(), DATE_SUB(), YEAR(), MONTH()
- Running totals and statistical analysis
